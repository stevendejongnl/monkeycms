Theme tokens

Every colour, size and font in MonkeyCMS is one CSS custom property on the page. Set any of them on :root or on the monkey-app element. Nothing else needs to change. Open the Tweaks panel on this board to try a theme.

Colours

--monkey-background-colorPage background
--monkey-surface-colorCards, tables, inputs
--monkey-colorBody text
--monkey-muted-colorHints and table heads
--monkey-border-colorDividers and card edges
--monkey-control-border-colorInput and button borders
--monkey-accent-colorPrimary button, active item
--monkey-accent-contrast-colorText on the accent
--monkey-link-colorLinks and badges
--monkey-error-colorError text and borders

Shape, space and type

--monkey-radiusCorner of buttons, inputs and cards. Default 8px.
--monkey-gap · --monkey-field-gap · --monkey-paddingSpace between blocks, inside a field, and in table cells.
--monkey-fontOne font stack for all text. Any web-safe or loaded font.Aa Bb Cc 123

Use it

:root {
  --monkey-accent-color: #5B4BDB;
  --monkey-radius: 8px;
  --monkey-gap: 24px;
  }

Dark mode is the same tokens with other values. Put them in a prefers-color-scheme: dark block or on a class of your choice.

Presets

A preset is a set of values for the tokens above. The same values can go in a theme object in the config: mode, accent, radius, density and font. The app turns them into the tokens. Any CSS you add on top wins.
